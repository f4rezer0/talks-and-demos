## Come aggiungere il proprio intervento

1. Crea una sottocartella `linux_day_2026/argomento_del_talk` (minuscolo, senza spazi).
2. Copia al suo interno `_template/README.md` e compilalo.
3. Aggiungi le slide in PDF (`slides.pdf`) ed eventuale codice o sorgenti delle slide.
4. Aggiungi una riga alla tabella "Interventi" qui sopra.
5. Fai push seguendo le istruzioni del [README principale](../README.md). Se non fai parte dell'organizzazione, apri una Pull Request da un fork: vedi [Se non fai parte dell'organizzazione](../README.md#se-non-fai-parte-dellorganizzazione).

Per video o file oltre i 50 MB inserisci un link nel README dell'intervento invece di caricare il file.

Salvo diversa indicazione nella cartella dell'intervento, i materiali seguono la [licenza del repository](../LICENSE).
